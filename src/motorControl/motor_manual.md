# TROY AGV-BLD-2S 直流無刷驅動器綜合說明書

本說明書整合了《AGV-BLD-2S 使用篇》與《通訊篇》之內容，旨在為技術人員提供關於 **泰映科技 (TROY)** 生產之 AGV-BLD-2S 驅動器的硬體安裝、控制邏輯及通訊協議的詳細指引。

---

## 1. 產品概要與安全規範

### 1.1 產品特點
* **1 驅 2 模式**：單一驅動器可同時控制兩台馬達，特別針對 AGV 的差速轉向控制需求設計。
* **低功率設計**：適用於輸出功率低於 **100W** 的直流無刷馬達。
* **多元控制**：支援 I/O 信號、模擬電壓（0-5V）、RS-485 (Modbus/HS)、RS-232 及 CAN BUS 通訊。

### 1.2 安全注意事項
* **環境限制**：嚴禁在爆炸性、易燃性、腐蝕性環境或沾水處使用。
* **電源警告**：輸入電壓務必控制在額定範圍內，電源正負極接反會造成損壞 。
* **操作規範**：保養與檢查必須在切斷電源後進行，且嚴禁擅自拆解或改造產品。

## 2. 硬體安裝與接線說明

### 2.1 安裝規範
* **尺寸**：主體尺寸為 $140 \times 88 \times 30$ mm。
* **散熱要求**：驅動器底板具備散熱功能，安裝時必須與外殼接觸。若馬達在 200W 負載下連續運轉，建議散熱鋁板需大於 $140 \times 90$ mm。
* **空間預留**：驅動器周邊應預留 2 cm 以上的通風空間。



### 2.2 端口定義
驅動器面板包含以下主要接線端子：

| 端口編號 | 功能名稱 | 說明 |
| :--- | :--- | :--- |
| **CN1** | 驅動器電源端子 | 額定電壓 DC 24V，允許範圍 18V-29V 。建議線材 AWG10。 |
| **CN2 / CN3** | A / B 馬達端口 | 連接馬達霍爾信號與動力線。 |
| **CN4 / CN6** | 控制信號端子 | 22 針腳，包含 I/O、模擬量及所有通訊接口。 |

## 3. 控制模式與參數配置

在正式運轉前，必須透過 **RS-232** 接口連接 PC 配置軟體，設定以下關鍵參數：

### 3.1 關鍵配置參數表 [cite: 147, 886, 897]
* **設備介面及協議**：可選 RS232-HS、RS485-HS、CANBUS-HS、Modbus 或模擬量控制。
* **馬達極對數**：須依馬達型號設定（例如：6B20 為 2P；9B100 為 4P）。
* **通訊 ID**：範圍 1-127。
* **通訊速率**：RS-485 最高支援 115200bps；CAN BUS 最高支援 1000Kbps。
* **保護電壓**：欠壓保護（默認 12V）與過壓保護（默認 30V）。

### 3.2 I/O 控制信號 (CN4 接口) [cite: 763-805]
* **輸入信號 (X0-X5)**：
    * **X0 (使能)**：ON 為使能狀態；OFF 為馬達失控狀態。
    * **X1 / X2**：分別控制 A / B 馬達制動（OFF 為電磁制動狀態）。
    * **X3 / X4**：分別控制 A / B 馬達方向（OFF 正向；ON 反向）。
    * **X5**：故障清除信號。
* **速度輸入 (V1 / V2)**：
    * 透過 **DC 0-5V** 模擬電壓控制轉速，範圍為 **100 - 3000 r/min**。

## 4. 通訊協議詳解

### 4.1 Modbus RTU (RS-485)
使用 Modbus 協議時，驅動器作為從站執行指令：
* **常用功能碼**：讀取寄存器 (04h)、寫入多個寄存器 (10h)。
* **重要寄存器地址**：
    * **2002 / 2003 (寫入)**：設定 A / B 馬達控制（01:控制運轉；03:立即制動）。
    * **2004 / 2005 (寫入)**：設定 A / B 馬達運轉方向（0:正向運行；1:反向運行）。
    * **2006 / 2007 (寫入)**：設定 A / B 馬達轉速值。
    * **1002 / 1003 (讀取)**：讀取 A / B 馬達實時轉速。
    * **1005 (讀取)**：讀取當前故障代碼。

### 4.2 HS 協議 (自定義通訊)
HS 協議採用固定長度的封包格式，具備較高的即時性：
* **詢問封包 (Master -> Slave)**：起始碼 (AA) + 地址 + 返回數據類型 + 故障清除 + 保留位 + A/B馬達控制/方向/轉速 + 結束碼 (55) + CRC16 。
* **應答封包 (Slave -> Master)**：起始碼 (55) + 地址 + A/B馬達電流/轉速 + 電源電壓 + 故障狀態 + 結束碼 (AA) + CRC16。

### 4.3 CAN BUS 通訊
* **規格**：CAN BUS 2.0A 標準幀，數據長度 8 Byte。
* **數據格式**：包含馬達選擇、返回數據控制、故障清除、運行控制、方向及 2-Byte 轉速值。

## 5. 故障排除與保養

### 5.1 LED 故障代碼表
當發生異常時，驅動器上的紅色 LED 會閃爍特定次數，對應如下：

| 閃爍次數 | 故障說明 | 建議處理措施 |
| :--- | :--- | :--- |
| **1 / 2** | A / B 馬達短路保護 | 檢查馬達線路及繞組是否異常。 |
| **3 / 4** | A / B 馬達超載保護 | 檢查負載是否超出規格，馬達是否過熱 。 |
| **5 / 6** | A / B 馬達堵轉保護 | 檢查機械結構是否卡住。 |
| **7 / 8** | 霍爾感測器錯誤 | 檢查馬達霍爾信號接線是否鬆脫 。 |
| **10 / 11** | 欠壓 / 過壓保護 | 檢查輸入電源電壓是否穩定於 DC 24V。 |
| **常亮** | 正常狀態 | 驅動器運行正常。 |

### 5.2 定期點檢
由於 AGV 長期處於震動環境，建議每 **6 個月** 點檢一次：
* 檢查驅動器 PCB 與外殼固定螺母的鬆緊度 。
* 檢查表面是否有異物或灰塵堆積，避免散熱不良。
* 確認通訊及動力端子接線有無鬆動。

## 附錄：CRC16 校驗函數 (C 語言)
通訊協議中使用的校驗碼計算邏輯如下：
```c
unsigned int wCrc = 0xFFFF;
unsigned int wPolynom = 0xA001;
for (i = 0; i < iBufLen; i++) {
    wCrc ^= Buffer[i];
    for (j = 0; j < 8; j++) {
        if (wCrc & 0x0001) {
            wCrc = (wCrc >> 1) ^ wPolynom;
        } else {
            wCrc = wCrc >> 1;
        }
    }
}
return wCrc;
```
